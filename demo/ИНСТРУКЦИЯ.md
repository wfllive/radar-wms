# Инструкция — радарная карта (без JavaScript!)

## Файлы

| Файл | Назначение |
|------|-----------|
| `demo/radar-min.html` | ⭐ Карта **без JS** — чистый HTML: `<img>` + `<a>` |
| `demo/proxy-nowcast.js` | Прокси: получает токен и впрыскивает в WMS-запросы |
| `demo/radar-viewer.html` | Продвинутая версия с JS (анимация, таймстемпы, JWT-декодер) |

---

## Как запустить (2 шага)

```bash
# Шаг 1 — запустить прокси
node demo/proxy-nowcast.js

# Шаг 2 — открыть в браузере
open demo/radar-min.html
# или: python3 -m http.server 8000 -d demo/ → http://localhost:8000/radar-min.html
```

---

## Как это работает

```
radar-min.html (ноль JS)         прокси localhost:8015         nowcast.ru
        │                              │                          │
        ├── <img src=".../baltrad_wsgi?LAYERS=bufr_phenomena...">
        │                              │                          │
        │   Браузер делает GET ──────►│                          │
        │                              ├── +token (авто!) ───────►│
        │                              │◄── PNG картинка ────────┤
        │◄── PNG картинка ────────────┤                          │
```

### Прокси делает всё сам:

- 🔑 При старте получает токен с `nowcast.ru/get_token`
- 🔄 Обновляет каждые 30 секунд
- 💉 Впрыскивает токен во все WMS-запросы
- 🌐 Добавляет `Referer: nowcast.ru`
- ✅ Добавляет `Access-Control-Allow-Origin: *`

### HTML — чистый, без JS:

- `<img>` теги — браузер сам загружает картинки (CORS не нужен)
- `<a>` ссылки — клик для открытия крупного изображения
- Ни одной строчки JavaScript

## Прямые ссылки

| Что | URL |
|-----|-----|
| Токен | `http://localhost:8015/get_token` |
| GetCapabilities | `http://localhost:8015/baltrad_wsgi?SERVICE=WMS&REQUEST=GetCapabilities` |
| GetMap | `http://localhost:8015/baltrad_wsgi?SERVICE=WMS&REQUEST=GetMap&LAYERS=bufr_phenomena&FORMAT=image/png&SRS=EPSG:4326&BBOX=30,50,45,60&WIDTH=800&HEIGHT=600` |

Токен добавляется автоматически — не нужно передавать `?token=...`.
